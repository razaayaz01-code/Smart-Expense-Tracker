# 📊 Smart Expense Tracker & Budget Analysis System (Python)

## 1. Project Overview
The Smart Expense Tracker & Budget Analysis System is an intermediate-level Python application developed to record daily expenses, analyze spending patterns, and generate monthly financial reports.  
The project supports both Command-Line Interface (CLI) and Graphical User Interface (GUI) using Tkinter.

---

## 2. Objectives
- Track daily expenses efficiently  
- Analyze category-wise spending  
- Generate monthly expense reports  
- Provide both CLI and GUI-based interaction  
- Store data persistently using CSV files  

---

## 3. Key Features
- Add expenses with category, amount, and description  
- View total expenditure  
- Category-wise expense analysis  
- Budget limit checking  
- Expense visualization using charts  
- Monthly expense report (month & year based)  
- GUI-based expense entry using Tkinter  
- Automatic CSV file creation and storage  

---

## 4. Technologies Used
- Python 3

## 6. GUI Description (Tkinter)
The GUI version provides a simple and interactive interface that allows users to:
- Enter expense details using input fields  
- Add expenses with a button click  
- Receive popup notifications  
- Store data in the same CSV file used by the CLI version  

---

## 7. Monthly Report & Chart Feature
The Monthly Report feature allows users to:
- Enter a specific month and year  
- View category-wise expense totals  
- Calculate total monthly expenditure  
- Visualize expenses using bar charts  

This feature is implemented using Pandas for data filtering and Matplotlib for visualization.
