# Smart Expense Tracker & Budget Analysis System

## 📌 Project Overview
The Smart Expense Tracker is a Python-based application that allows users to
record daily expenses, analyze spending patterns, and monitor monthly budgets.
It helps users understand where their money is spent and promotes better
financial planning.

---

## 🎯 Objectives
- Track daily expenses
- Categorize spending
- Analyze total and category-wise expenses
- Check budget limits
- Visualize expense distribution

---

## ⚙️ Features
- Add daily expenses
- Automatic CSV file generation
- Category-wise expense analysis
- Budget exceed warning
- Pie chart visualization of expenses

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- CSV file handling
